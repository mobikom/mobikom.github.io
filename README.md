## ⚡ Core Engineering Principles

* **The 512-Byte Principle:** Minimalist markup and zero runtime bloat delivering near-instant First Contentful Paint (FCP) and optimal energy efficiency.
* **Zero External Dependencies:** No JavaScript frameworks, no third-party CDNs, zero tracking pixels, and no external Google Fonts requests.
* **Pure CSS Grid Level 2 & Subgrid:** Native browser layout alignment with automated subgrid card alignment and graceful legacy fallbacks.
* **Strict Single-Page A4 Print Engine:** Executive CV (`/stoyanov/`) calibrated with precision print CSS (`@media print`) to fit strictly onto one single A4 page for PDF archiving.
* **Hardened Edge Security:** Proxied via Cloudflare with full HTTPS encryption, strict HSTS, `X-Frame-Options: DENY`, `nosniff`, and custom Content Security Policy (CSP).
